# Student Marks & Grade Checker

## Description
A Python program that takes a student's name and subject marks, calculates the total obtained marks, percentage, and final grade.

## Features
- Takes student information and marks as input.
- Calculates total marks.
- Calculates obtained marks and percentage.
- Assigns a grade based on the student's performance.
- Displays the final result.

## Technologies Used
- Python 3
